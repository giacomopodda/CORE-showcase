# CORE!

> A modular platform for building reusable websites and web applications.

CORE! is designed to separate the front-end structure from content, making it easier to adapt a web project to different sectors while keeping a consistent development and publishing workflow.

## Product directions

### BUILD
A website model for construction companies and related businesses. It can include services, project portfolios, reviews, FAQs, service areas and an administrative panel.

### LEGGI
A website model for hospitality and food-service businesses, adaptable to hotels, B&Bs, restaurants and venues, with an administrative panel for managing content.

## Architecture at a glance

CORE! is organised around reusable building blocks:

- **Components** - shared interface elements.
- **Layouts** - page structures reusable across projects.
- **Renderer** - content-to-page rendering workflow.
- **Themes** - visual variations for different brands and sectors.
- **Utilities** - shared helpers and integrations.
- **Engine** - platform-level orchestration and configuration.

## Publishing workflow

`Content → Decap CMS → private GitHub repository → Netlify → published website`

Content changes can be saved, versioned and deployed without directly editing the front-end code.
